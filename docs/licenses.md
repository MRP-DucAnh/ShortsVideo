# Dependencies và giấy phép

| Thư viện | Công dụng | Giấy phép / điều khoản |
|---|---|---|
| Kotlin, kotlinx.coroutines | Ngôn ngữ và concurrency | Apache 2.0 |
| AndroidX Compose, Lifecycle, Navigation, DataStore, Media3 | UI, state, navigation, persistence và video | Apache 2.0 |
| OkHttp | HTTP với timeout/cache policy rõ ràng | Apache 2.0 |
| Coil | Load/cache poster | Apache 2.0 |
| Firebase Remote Config | Kill switch quảng cáo từ xa | Firebase / Google SDK terms |
| Google Mobile Ads | Quảng cáo test | Google SDK terms |
| JUnit, AndroidX Test | Unit/instrumentation tests | EPL 1.0 / Apache 2.0 |

Danh sách này là ghi chú dependency cho bài test, chưa phải màn third-party notices hoàn chỉnh để phát hành. Metadata/poster/video đến từ endpoint đề bài, không khẳng định quyền tái phân phối nội dung cho sản phẩm thương mại.
